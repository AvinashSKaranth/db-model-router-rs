# E1: Book catalog CRUD

Build a library crate named `app` that uses `dbmr` (SQLite).

Expose exactly:

```rust
pub async fn build_app(db: std::sync::Arc<dbmr::adapters::SqliteAdapter>) -> dbmr::Result<axum::Router>;
```

`build_app` must create its own table if it does not exist, and mount a REST router at `/books`.

Table `books`:
- `id`: auto-increment primary key;
- `title`: required, max 200 characters;
- `author`: required string;
- `year`: integer, optional;
- `isbn`: required string, unique.

The standard dbmr HTTP contract applies:
- create one book with `POST /books/0`;
- bulk-create with `POST /books` and body `{"data":[...]}`;
- read, update and delete through `/books/{id}`;
- filter with query parameters such as `?author=X` or `?year=>=2000`.

A missing required field must produce 422.
