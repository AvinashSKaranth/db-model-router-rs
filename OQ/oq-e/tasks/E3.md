# E3: Authors and nested books

Build a library crate named `app` that uses `dbmr` (SQLite). Expose:

```rust
pub async fn build_app(db: std::sync::Arc<dbmr::adapters::SqliteAdapter>) -> dbmr::Result<axum::Router>;
```

It must create these tables if missing:
- `authors`: `id` (auto-increment primary key), `name` (required);
- `books`: `id` (auto-increment primary key), `author_id` (required integer), `title` (required).

Routes:
- `/authors`: full REST for authors;
- `/books`: full REST for all books;
- `/authors/{author_id}/books`: REST for books scoped to one author.
  - Creating a book here sets `author_id` from the path.
  - Listing returns only that author's books.
  - Reading, updating or deleting a book through another author's path returns 404.
