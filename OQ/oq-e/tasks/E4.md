# E4: Atomic account transfer

Build a library crate named `app` that uses `dbmr` (SQLite). Expose:

```rust
pub async fn build_app(db: std::sync::Arc<dbmr::adapters::SqliteAdapter>) -> dbmr::Result<axum::Router>;
pub async fn transfer(db: std::sync::Arc<dbmr::adapters::SqliteAdapter>, from: i64, to: i64, amount: i64) -> dbmr::Result<()>;
```

`build_app` must create table `accounts` if missing:
- `id`: auto-increment primary key;
- `owner`: required;
- `balance`: required integer.

Mount REST at `/accounts`.

`transfer` moves `amount` from account `from` to account `to` in one database transaction.
- If `from` has insufficient balance, it returns an `AppError` with HTTP status 422.
- On failure, neither balance changes.
- A missing account returns status 404.
