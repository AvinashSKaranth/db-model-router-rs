# E5: Tasks with soft delete, search and CSV export

Build a library crate named `app` that uses `dbmr` (SQLite). Expose:

```rust
pub async fn build_app(db: std::sync::Arc<dbmr::adapters::SqliteAdapter>) -> dbmr::Result<axum::Router>;
```

It must create table `tasks` if missing:
- `id`: auto-increment primary key;
- `title`: required;
- `status`: required, either `open` or `done`;
- `is_deleted`: integer, not null, default 0.

Mount REST at `/tasks`. Requirements:
- `DELETE /tasks/{id}` must soft-delete: the row stays in the table with `is_deleted = 1`, and is hidden from all API reads.
- `GET /tasks?search=term` searches `title`.
- `GET /tasks?output_content_type=csv` returns CSV.
- An invalid `status` is rejected with 422.
