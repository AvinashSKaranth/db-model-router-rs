Methodology & Fairness Guarantees

  • Sequential Isolated Execution: All contenders execute in isolation against the dedicated PostgreSQL 16 container, eliminating CPU, connection pool, or memory contention.
  • Deterministic Dataset: Before each contender run, the database is completely reset (TRUNCATE bench_items, bench_audit RESTART IDENTITY CASCADE) and pre-seeded with 2,000 deterministic rows.
  • Public Model API: Both the Rust library and Node ORMs are exercised strictly through their public high-level model APIs (e.g. model.insert(), model.byId(), model.find(), model.update()) with full validation enabled.
  • Consistent Pool Ceiling: All contender clients connect with a maximum pool size of 10 connections.
  • Precision Percentiles: Latency measurements are captured around each individual operation via monotonic microsecond clocks, computing mean, min, max, p50, p95, and p99 percentiles using nearest-rank index ranking.
