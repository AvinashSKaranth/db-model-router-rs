dbmr (db-model-router-rs)

Database-agnostic models and generated Axum REST routers for Rust services. Rust rewrite of the Node.js db-model-router: same HTTP behaviour, except the documented deviations. Library only: models and routers. Your application owns its DDL.

Reports

Quality report

Test cases, coverage, dependency audit (cargo-deny, cargo-audit), static scan, secret scan, clippy, rustfmt, traceability, rustdoc, run history. Regenerated by the pre-push hook.

Benchmark

PostgreSQL scenarios (inserts, bulk writes, reads, filters, sort/limit) against Node ORMs and the Node db-model-router. Produced by crates/dbmr-bench.

The quality report is generated locally and not committed. If the link is broken, run python scripts/report.py (needs the docker-compose services, or pass --offline).

Features

  • CRUD, bulk writes, filters, search, paging, CSV/XML export over generated Axum routes (incl. QUERY)
  • Row-level scope from your auth middleware, enforced by the model (tenants, owners, nested routes; fail closed: 401)
  • Soft delete, hidden columns, field encryption, app-side created_at/modified_at
  • Optimistic locking (ETag/If-Match, 409/428)
  • Relations with ?include=, typed models, transactions on every SQL adapter
  • RouterOptions (read-only routers), OpenAPI 3.1, health route
